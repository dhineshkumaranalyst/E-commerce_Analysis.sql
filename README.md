# E-commerce_Analysis.sql
E-Commerce Sales Analysis using SQL is a data analytics project that analyzes customer orders, product sales, revenue, and order status using SQL. The project uses SQL queries, joins, aggregate functions, subqueries, CTEs, and CASE statements to generate useful business insights.

💡 Strong Business Insights

1. Electronics dominates sales
Electronics generated ₹1,69,600, making it the largest revenue-generating category in this dataset.

2. Laptop is the major revenue contributor
Laptop alone generated ₹1,10,000, significantly contributing to the overall January revenue.

3. Most orders were successfully delivered
There were 6 Delivered orders, compared with 2 Shipped, 1 Cancelled and 1 Processing.

4. Arun Kumar is the highest-spending customer
Arun Kumar spent ₹59,000, followed by Naveen Kumar at ₹55,800.

5. Order value is mostly from delivered orders
Delivered orders account for ₹1,76,000 of the ₹1,89,400 total order value.
